## Production notes (all Reels)
- **Aspect**: 9:16, 1080×1920. Text safe-zone: keep captions in middle 70% (avoid top/bottom UI).
- **Captions ON always** — 80% watch muted. Big bold text, one line at a time.
- **Music**: trending audio from IG library (owner ads = upbeat corporate; guest ads = chill/travel). Original VO layered under.
- **Hook rule**: no logo/intro first 3s. Start on problem or reveal.
- **CTA**: spoken + on-screen + sticker. One clear action only.
- **A/B test**: run same script 2 ways — Tamil vs Hinglish, or hook A vs hook B. Kill losers after 48h.
- **Owner ads** → target: business owners 28–55, interests hotel/restaurant management, {{CITY}} + Tamil Nadu.
- **Guest ads** → target: travelers 22–45, interests travel/weekend getaway, 60–120km radius around {{HOTEL}}.
